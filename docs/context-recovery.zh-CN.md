# 本地上下文恢复

`context_recovery` 针对 Codex `app_server` 的明确 `invalid_encrypted_content` 终态错误，可处理恢复旧会话失败、发送输入失败和运行中的回合失败。默认关闭；普通助手文字、其他 400 错误和仍在重试的通知不触发：

```toml
[projects.agent.options]
backend = "app_server"
context_recovery = false
```

后续经部署授权后才可改为开启。`exec` 后端不能开启此选项。必须有可持久化的会话存储，并能确认本机旧执行器和读取协程已经结束；不对无法确认停止的外部 WebSocket 执行器重建上下文。

## 任务如何继承

正常会话沿用已有可见历史和宿主输入记录，**不要求模型定期写总结、状态表或检查点**。故障发生后，程序才整理材料：原任务输入、用户可见历史、工具输入和结果、定时或 IPC 来源，以及当前已知的输入回执。

程序先持久保存一次恢复尝试，确认旧执行器停止，再按旧执行器实际使用的模型、思考档位、工作目录、权限、前导指令、可执行文件和环境创建干净上下文。新旧绑定保存成功后，带入恢复期间收到的最新修改，发送一次续接指令。准备阶段最多 90 秒，同时受原回合剩余时间限制；`/stop`、`/new`、`/switch` 优先，迟到的新执行器会被关闭。`/ps` 补充也会保留，恢复准备或首条输入尚未确认时进入队列。

新模型会明确知道是在承接原任务，并被要求先核对进度：材料可能不完整，应按原授权主动补查相关规则、文件、成果和作业回执；遵守最新修改、取消和暂停要求；已完成的动作不重做，结果不明的动作先核实，仍不明时只暂停对应部分；已有后台任务继续查收或等待。恢复不会增加部署、访问范围或上游调查授权。

程序能确定输入来源、执行和绑定等事实；任务含义与实际完成程度由模型结合工作区证据核对。缺失材料会标明，不会由程序猜出一个“已经完成”的状态。

## 次数、材料与回执

- 同一宿主会话承接链最多自动重建一次。换 native ID、发下一条消息、重启进程、成功回复都不清零；显式切回该链已知的祖先 native ID 也继承次数，目标仍是用户选中的那个 ID。`/new` 建立新的宿主会话。
- 正常输入送达、模型回合完成和业务任务完成分别看待。当前恢复阶段、原输入摘要、新旧 ID、来源和错误保存在 `Session.context_recovery`；`model_turn_completed` 仅表示模型回合完成。
- 会话存储旁的 `context-recovery/<id>/visible-material.json` 保存过滤后证据和准备快照，`continuation.txt` 保存实际续接输入。目录权限 `0700`、文件 `0600`，拒绝材料目录软链接；这些运行材料不应提交到代码仓库。
- 导出核对准确原生日志 ID、规范工作目录、唯一文件和非子 Agent 元数据，排除 analysis、reasoning、内部总结、密文和原始 system/developer 对象。原生日志路径只作来源定位，模型使用过滤后的材料。
- 原生日志单行最多 4 MiB，超长行跳过后仍继续读取；单项最多 256 KiB，全部可见项最多 16 MiB／8192 项，保留开头和最新部分并标明缺口。首条续接输入最多 96 KiB，优先原输入和最新用户更新；完整可用导出留在材料文件。附件元数据保留名称、类型、大小、数量，当前内存中的附件随新回合提供。
- 重启时发现准备或发送中断，不自动重放；旧执行器退出不明或持久化失败，也会阻止普通路径继续复用。继续前核对材料、进程、绑定和实际动作回执。

定时任务继续原来的那次触发，不重新预约或再触发。提示词回合失败会传回调度器，静默任务也一样；shell 定时任务仍只执行原命令，若经 IPC 投入模型，则按原 IPC 输入承接。

IPC 回执只增加独立的 `context_recovery` 字段，原输入及哈希、原目标、送达状态和 ACK 均不改写。当前已受理输入可继续，送达不明的 steer 作为待核对证据；之后仍指向旧 native ID 的事件和 ACK 不会自动改投新会话。通用回调迁移与完整 IPC 重构不在本功能内。

## 验证范围

测试全部使用临时目录、假 Agent 和本机 fake app-server，覆盖三类故障入口、排队消息、晚到修改、停止和切换、退出与写入失败、重启及祖先会话次数、回执先后顺序、定时错误、固定 IPC 目标、历史过滤及材料权限。CUJ A9、A10 从 `ReceiveMessage` 验证用户连续修改任务与恢复期间停止。没有通过真实模型调用或上游探针验证。

英文说明与字段解释见 [Local context recovery](context-recovery.md)。
